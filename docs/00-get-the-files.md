# Step 0 – Get the lab files

[⬅ Back to README](../README.md) | [Next: Prepare your content ➡](01-prepare-your-content.md)

You need two things from this repo on your computer: the **template** (`templates/Portfolio_Data.xlsx`) and the **prompts** (`prompts/`).

## Option A – Download ZIP (easiest)
1. On this repo's GitHub page, click the green **`<> Code`** button → **Download ZIP**.
2. Extract it:
   - **Windows:** right-click the `.zip` in **Downloads** → **Extract All...** → **Extract**.
   - **macOS:** double-click the `.zip`.
3. Open the extracted folder → **templates** → you should see **Portfolio_Data.xlsx**.

## Option B – Git
```bash
git clone https://github.com/SHADRACK-NAKOBA/portfolio-website-lab.git
cd portfolio-website-lab
```

## Open the template
- **Have Excel?** Double-click **Portfolio_Data.xlsx**.
- **No Excel?** Use free Excel online: go to https://www.office.com → sign in with any Microsoft account → **Upload** → choose the file. Or upload it to **Google Sheets** (https://sheets.google.com → **File → Import → Upload**). When you finish, download it again as **.xlsx** (Google Sheets: **File → Download → Microsoft Excel (.xlsx)**).

> ⚠️ If Excel shows a yellow bar **"PROTECTED VIEW – Enable Editing"**, click **Enable Editing**, otherwise you can't type.
