# Prompt 2 – Ready-made refinement prompts

Use these in [Step 3](../docs/03-refine-your-design.md). Paste **one at a time** into the chat beside your design, wait for the update, check it, then do the next.

> **Chat or comment?** Use the **chat** for changes to the whole page (new sections, layout, colours). Use **inline comments** (click on the canvas) for one small element. If a comment doesn't seem to work, paste the same request into the chat.

## Look and feel
```
Make the design more minimal: more white space, fewer borders, one accent colour only.
```
```
Use #2348C5 as the accent colour everywhere (buttons, links, highlights).
```
```
Add a light/dark mode toggle in the navigation bar. Default to dark.
```
```
Make the hero more impressive: larger name, my title in the accent colour, and a subtle
animated gradient in the background. Keep it professional, not flashy.
```

## Content
```
Merge any duplicate or overlapping skill rows into one clean row each
(for example "Cloud" and "Cloud Engineering" into one "Cloud" row).
```
```
Rewrite my project cards so each one reads: Problem -> What I built -> Result,
in short sentences. Do not invent any numbers or facts.
```
```
Add this project as the FIRST project card:
Name: <name>
Problem: <one line>
What I built: <one or two lines>
Tech: <comma separated>
Result: <one line>
Link: <GitHub URL>
```
```
Add a "Download resume" button in the hero and the contact section that links to resume.pdf.
```

## Checks
```
Check the whole page on a phone-sized screen and fix anything that overflows, overlaps or
is too small to read.
```
```
Check every link on the page: email (mailto:), LinkedIn, GitHub and project links must use
exactly the URLs from my spreadsheet. List them so I can verify.
```
```
Remove any placeholder text, invented details, or content not from my spreadsheet.
```
